Web logs

What browsers report while the web app loads and runs, newest first (kept 14 days). Failed: it broke before the first screen. Slow: still loading after 20 s / 60 s, with how far it got. Started: the first screen showed, with the load time and the device. Crash: an error inside the running app. Performance: frames a second (60 is smooth; under 30 feels slow) at 1 and 3 minutes in.
Crashes carry the error's stack trace (where in the app it broke): Download saves one report as a text file, Download all saves everything shown.
